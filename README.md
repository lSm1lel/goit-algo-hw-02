# goit-algo-hw-02

Домашнє завдання до теми 2 «Основні структури даних».

## Завдання 1

Реалізовано систему обробки заявок сервісного центру.

Використовується клас `Queue` з модуля `queue`.

Програма:

- генерує заявки з унікальними номерами;
- додає їх до черги;
- послідовно отримує заявки з черги;
- імітує їх обробку.

Файл: `task_1.py`

## Завдання 2

Реалізовано перевірку рядка на паліндром.

Використовується `deque` з модуля `collections`.

Програма:

- не враховує регістр;
- не враховує пробіли;
- працює з рядками парної та непарної довжини;
- порівнює символи з обох кінців черги.

Файл: `task_2.py`
